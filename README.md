# Vlo: Школа Выживания (Fabric 1.21.1)

Кооп на двоих (Open to LAN) или соло. Сюрреалистичная школа V LO, Białystok.

## Сборка
1. Java 21 + Gradle 8.8+ (`gradle wrapper` создаст gradlew) или откройте проект в IntelliJ IDEA.
2. `./gradlew build` -> `build/libs/vlo-school-1.0.0.jar` в папку `mods/` (+ Fabric API 0.105.0+1.21.1).
3. Версии в `gradle.properties` (yarn/loader/fabric api) при необходимости обновите под 1.21.x.

## Игра
- Создайте мир (лучше плоский/равнинный), встаньте на ровное место, `/vlo start` — школа построится рядом, всех телепортирует в гардероб.
- Для друга: Esc -> Open to LAN, друг заходит по локальной сети. Сюжет общий.
- `/vlo quest` — текущая цель, `/vlo tp` — в гардероб, `/vlo stage N` и `/vlo reset` — для операторов.
- Креатив-вкладка «Vlo: Выживание в школе» — все предметы и яйца призыва.

## Сюжет (6 стадий)
1. Адрик просит 2 «Энергетик Flash» -> пуховик.
2. Пани Кристина: 3 домашки.
3. Пан Богдан: долг 10 злотых.
4. Пан Збигнев: шпаргалка из учительской -> ключ.
5. Люк в кабинете директора -> подвал -> Аттестат -> Адрик.
6. Выпуск: директор уходит на пенсию, выход открыт.
Плюс побочки Адрика (печеньки, бульба, бумажки, хлеб).

## Директор (честные правила)
Шаги слышно издалека, предупреждения в actionbar; заметил -> 2 сек крика -> погоня максимум 12 сек
(чуть медленнее спринта); присесть = видит с 6 блоков; шпаргалка (Shift+ПКМ) = с 3 блоков;
не убивает никогда (урон <= HP-1, при низком HP — «воспитательная беседа» в Поправочной);
после поимки/усталости — перекур 8–15 сек. Чих/ронянье учебника Адриком привлекает его.

## Заметки
- Код написан под Yarn 1.21.1; если компилятор ругнётся на имя метода — это мелкие правки маппингов.
- Скины — ванильные дефолтные (steve-family). Хотите очки Адрику — нарисуйте PNG и подключите в VloClient.
- `/vlo start` отключает spawn мобов в мире (gamerule doMobSpawning=false), чтобы школа была только вашей.
